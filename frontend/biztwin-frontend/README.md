# BizTwin AI — Frontend prototype

A responsive React + Vite dashboard prototype using a forest-green, warm-neutral and muted-orange palette.

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm

## Run locally
1. Extract the ZIP file.
2. Open the `biztwin-frontend` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Included pages
- Dashboard
- Semantic Graph
- Deep Learning Forecasting
- What-If Simulator
- Financial What-If Analysis
- AI Translation & Business Assistant
- Data Manager
- Model Lab
- Settings

## Important
This is a **frontend prototype**. It includes illustrative/sample values and client-side interactions so you can explore the screens. It does not yet upload/process real files, train ML/DL models, establish causal effects, save data to a database, or call a translation/LLM API. Those require a backend (for example, Python + FastAPI) and validated datasets/models. Replace all sample metrics with results from your own experiments before presenting them as measured results.
